# TG 115资源通道配置说明

## 兼容范围

- MoviePilot `>= 3.0.0`
- 建议使用 V3 最新镜像，并已配置至少一个有效的 MoviePilot 媒体下载目录
- Python `>= 3.12`
- Telegram 用户账号能够正常私聊目标资源机器人
- 资源机器人回复中最终能够取得 `115.com` 或 `115cdn.com` 分享链接

插件使用 MoviePilot V3 的 `search_torrents` / `async_search_torrents` 模块扩展点。当前 V3
会先请求插件资源源，再继续请求已启用的站点，因此插件资源在流式搜索中先出现；订阅仍由
MoviePilot 自己的识别、过滤、选种和下载治理流程决定是否采用。

MoviePilot 会在调用自定义下载模块前解析自己的媒体下载目录，因此即使本插件只做云端转存，
宿主中仍需存在一个可解析的下载目录。插件不会把 TG115 资源写入该本地目录，实际保存位置始终
是下方配置的 115 目录。

## Telegram 配置

1. 在 [my.telegram.org](https://my.telegram.org/) 为自己的 Telegram 用户账号申请
   `api_id` 和 `api_hash`。
2. 填写应用 ID、应用密钥和含国家区号的手机号（如 `+8613800138000`）。
3. 在“Telegram 登录操作”选择“发送验证码”，保存后重新打开配置查看状态。
4. 查看 Telegram 客户端或短信收到的验证码，填入“登录验证码”，选择“完成登录”并保存。
   如果提示需要两步验证密码，填写密码后再次选择“完成登录”并保存。
5. 成功后登录凭证会自动保存，无需手动生成 StringSession。验证码、密码和登录操作会在处理前从配置清空。
   待完成的登录请求有效期为 10 分钟；验证码实际有效期由 Telegram 决定。
   重发前先选择“取消本次登录 / 准备重发”并保存。修改手机号或应用配置后需要重新发码。
   新设备或异地登录若触发额外安全要求，请按官方客户端提示处理，插件不能绕过验证。
   服务器必须能连接 Telegram。登录状态可在配置顶部和插件详情查看。
6. 高级用户也可直接粘贴已有 StringSession；仓库脚本仍可用于手动生成。
7. 先用该 Telegram 用户账号手工 `/start` 目标资源机器人，确认账号有权使用。
8. 在插件中填写机器人用户名，不含或包含 `@` 都可以。
9. 根据机器人协议配置搜索模板，例如 `{keyword}`、`/search {keyword}`。

如果机器人先返回结果列表、点击“获取链接”后才返回 115 地址，可设置“详情按钮正则”，例如：

```text
^(获取链接|查看详情|115链接)$
```

插件只会点击无 URL 的 callback 按钮，并限制每次点击数。这个功能默认关闭。不要使用过宽的
`.*`，也不要误匹配“删除”“取消”“立即转存”等有额外副作用的按钮。

## 机器人回复解析

当前解析器支持：

- 回复正文中的 115 分享链接
- Telegram URL 按钮中的 115 分享链接
- URL 查询参数中的 `password`、`receive_code`、`pwd` 或 `code`
- 链接附近的“提取码 / 访问码 / 密码”
- 常见 KB/MB/GB/TB 大小和 720p/1080p/4K/REMUX 等质量文字

示例：

```text
沙丘2 (2024) 2160P REMUX 68.5GB
https://115.com/s/example?password=a1b2
```

如果实际机器人只返回按钮菜单、编辑原消息、要求多轮选择，或链接格式不同，需要用脱敏后的
真实回复样例补充适配器。请保留按钮文字、消息先后顺序和 URL 域名/路径形状，可以替换分享码。

## 转存方式

### 115 直转

配置包含 `UID`、`CID`、`SEID` 的 115 客户端 Cookie，并选择“115 直转”。插件会：

1. 使用所选 115 目录的实际 ID，电影、电视剧等全部保存到同一个目录；
2. 解析分享码和提取码；
3. 调用 115 分享接收接口，把完整分享保存到目标目录；
4. 将成功结果作为一个 MoviePilot 下载任务结算。

### TG 命令转存

如果资源机器人本身负责转存，选择“TG 命令转存”，并填写命令模板。可用占位符：

- `{url}`：115 分享链接
- `{code}`：提取码
- `{path}`：统一的转存目标目录
- `{title}`：机器人回复中解析出的资源标题

模板必须包含 `{url}` 和 `{path}`。示例仅用于说明，必须按实际机器人协议修改：

```text
/save {url} {code} {path}
```

插件会先匹配失败正则，再匹配成功正则。只有明确命中成功状态才向 MoviePilot 返回成功。

## 搜索与订阅语义

- 手动搜索：展示 TG115 资源卡片；用户点击下载后转存。
- 订阅搜索：MoviePilot 过滤并选中 TG115 资源后自动转存。
- TG 无结果/超时/限流：返回空列表，普通站点继续工作。
- 相同关键词默认缓存 15 分钟，防止 MoviePilot 的重复搜索快速刷屏机器人。
- Telegram 对话在插件内部串行执行，避免并发搜索的回复相互串线。
- 资源令牌默认保留 168 小时；过期后点击会要求重新搜索。

插件不额外设置资源优先级，不按返回条数、收集消息数或详情点击数截断资源。
会返回本次收集到的全部有效资源；回复超时、收集静默时间和 Bot 请求额度仍然生效。
MoviePilot 的订阅规则仍可能过滤不满足质量条件的资源。

### Bot 请求频率

“Bot 请求统计时段（秒）”与“每个时段最多请求 Bot 次数”共同生效，默认任意连续 60 秒最多 5 次。
搜索发消息、点击详情按钮和 TG 命令转存共用额度；缓存命中不占额度。
达到上限时不发送新请求，搜索或转存会提示等待后重试；详情阶段保留已收到的资源。
普通保存配置不会重置额度，插件进程重启后重新计数。对同一个 Bot 的对话仍串行执行，避免回复混淆。

### 115 目录选择

1. 填写有效的 115 Cookie，开启“读取 / 刷新 115 目录”并保存。
2. 重新打开配置，在“115 转存目录”选择实际文件夹并保存。
3. 再次打开可继续进入其子目录，或选择“返回上一级”“根目录 /”。当前目录即统一转存目标。
4. 文件夹很多时会自动分页读取；浏览不会创建文件夹。读取失败时保留上次成功选定的目录并显示原因。

从旧版本升级时，统一目录先沿用旧兜底目录（若未配置则为根目录），请读取目录后确认选择。
TG 命令转存若使用目录选择器，同样需要 115 Cookie；命令模板中的 `{path}` 使用所选目录路径。

## 安全说明

- StringSession 相当于 Telegram 登录凭据；泄漏后应立即在 Telegram 中终止对应会话。
- 115 Cookie 泄漏后应立即退出对应 115 客户端会话并重新登录。
- 不要把任何真实凭据写入源码、Issue、日志截图或 GitHub Actions 变量输出。
- 建议为自动化使用独立 Telegram 账号，并先确认资源机器人及资源内容的使用授权。
